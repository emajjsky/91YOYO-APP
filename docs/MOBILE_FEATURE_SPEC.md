# 91YOYO App 移动能力规格

版本：v0.1  
平台基线：iOS 16+、Android 10+

本文定义 React Native App 的原生能力。微信小程序使用自己的播放器、上传和授权实现，但读取/写入相同 API DTO。

## 1. 视频练习播放器

### 功能

- 播放/暂停、进度拖动、全屏和系统音量控制。
- 倍速固定为 `0.5x`, `0.75x`, `1x`，切换后当前进度不重置。
- 镜像只翻转视频画面，控制栏、字幕和手势方向不翻转。
- 支持设置 A/B 区间循环；离开帖子后停止，进入全局练习页时可继续。
- 记录同一设备上最近播放位置；短于 30 秒且播放超过 90% 的视频从头开始。
- 发布者不允许下载时，不显示保存原文件入口；缓存只用于播放且受系统清理。

### 状态

`idle → loading → ready → playing/paused → ended`，任何阶段可进入 `error`。错误必须区分网络、资源不存在、不支持编码和解码失败，并提供重试。

### 技术建议

优先评估 Expo SDK 对应的 `expo-video`，不要用静态 `Image + Alert` 模拟播放。镜像放在视频渲染视图，A/B 循环由时间更新事件控制并限制回调频率。

### 验收

- iOS/Android 真机切换倍速和镜像均不重置进度。
- 10 分钟视频连续播放无明显音画漂移。
- 前后台切换、耳机拔出、电话中断后状态符合系统媒体规范。

## 2. 后台音频

### 功能

- 播放/暂停、拖动、上一首/下一首（有队列时）、倍速保持 1x。
- 展示曲名、作者、封面、时长、BPM 和可选波形。
- 支持后台、锁屏控制、蓝牙耳机和系统控制中心。
- 同一时刻只有一个全局音频实例；开始视频播放时默认暂停音乐。
- 每 5 秒或进入后台时保存进度，避免高频写存储。

### 技术建议

优先评估 Expo SDK 对应的 `expo-audio` 及其后台配置。Zustand 只保存播放器视图状态，原生播放实例是实际状态来源。

### 验收

- 锁屏 10 分钟不中断，锁屏进度和 App 内进度一致。
- 系统打断后不擅自恢复；用户主动播放后再继续。
- 网络断开时显示可恢复错误，不把缓冲状态误报为暂停。

## 3. 图片、视频和音频选择

- 图片最多 9 张；支持 JPEG/PNG/HEIC，上传前生成合理尺寸的预览图。
- 视频最多 1 个；允许常见 MP4/MOV，客户端检查 MIME、大小和时长。
- 音频最多 1 个；允许平台可稳定解码的 AAC/M4A/MP3。
- 具体文件大小上限由服务端配置返回，客户端不能硬编码唯一真值。
- 权限只在用户点击选择/拍摄时申请；拒绝后说明影响并提供系统设置入口。
- Android Photo Picker/iOS limited photo library 可用时优先使用，避免申请整个媒体库权限。

计划依赖需在实现时与 Expo 57 兼容矩阵核对：`expo-image-picker`、`expo-document-picker`、`expo-file-system` 和图片处理库。文档中的库名不是已安装声明。

## 4. 上传管理

- 上传任务显示文件名、进度、取消和重试。
- App 退到后台时遵循系统限制；回前台后查询媒体状态并继续或重试。
- 同一文件重试复用 `mediaId` 和 checksum，不重复创建对象。
- 发布按钮在媒体未 `ready` 前不可提交；处理较久时允许保存草稿。
- 本地临时文件在成功、取消或过期后清理。

## 5. 推送与深链

- 推送类型：评论、点赞聚合、关注、私信、Jam 变更和审核结果。
- 用户可按类型关闭通知；营销通知默认关闭。
- 点击通知通过稳定链接打开资源，如 `91yoyo://posts/{id}`，资源无权限或已删除时显示统一失效页。
- 推送正文不包含私聊全文或敏感资料。
- 设备 token 与用户、平台、App 环境绑定；退出登录立即解除当前 token。

建议使用 `expo-notifications`，生产凭据只放 EAS/CI secret。

## 6. 位置与 Jam

- 浏览城市列表不申请定位；“使用当前位置”和地图附近活动才申请前台定位。
- MVP 后续阶段不申请持续后台定位，不收集参与者轨迹。
- 发布活动允许手动搜索地点；数据库保存活动公开坐标和地点名。
- 地图 SDK 选型必须同时验证中国大陆地图数据、坐标系、隐私条款和 App Store/Android 分发要求，不能只按组件易用性决定。

## 7. 离线与缓存

- 会话使用安全存储；公开 Feed 可缓存最近成功页和媒体缩略图。
- 私聊正文和签名 URL不写入普通日志；敏感缓存退出登录时清理。
- 离线时允许浏览已有缓存和编辑草稿；点赞、评论和发布不静默假成功。
- 恢复网络后用户可明确重试，幂等键防止重复写入。

## 8. 可访问性与系统适配

- 所有图标按钮提供 accessibility label，点击区域至少 44x44pt/dp。
- 支持系统字体放大到 200% 时完成主要流程，不以固定高度裁切正文。
- 支持 Reduce Motion；重要状态不能只靠颜色表达。
- 纯黑主题遵循系统深色模式，键盘、状态栏和原生弹窗保持一致。

## 9. 发布配置检查

- 正式应用名、图标、启动图、iOS Bundle ID、Android package。
- 相册、相机、麦克风、通知和位置用途说明。
- iOS 后台音频 mode、Android 前台媒体通知和通知渠道。
- Universal Links/App Links 与自定义 scheme。
- 隐私清单、第三方 SDK 数据申报和账号注销 URL。
